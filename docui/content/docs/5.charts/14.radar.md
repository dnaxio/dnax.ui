**`{ type: 'radar' }`** compares several criteria: `x` is the **indicator**, `y` its value and `z`
the series — one polygon per value of `z`:

::prose-show-case
<dnax-demo-chart demo="radar"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const rows = [
  { team: 'Alpha', skill: 'Speed', value: 8 },
  { team: 'Alpha', skill: 'Power', value: 6 },
  { team: 'Beta', skill: 'Speed', value: 5 },
  { team: 'Beta', skill: 'Power', value: 9 },
  // …
]
</script>

<template>
  <q-chart
    title="Skills, two teams"
    :height="300"
    :marks="[{ type: 'radar', data: rows, x: 'skill', y: 'value', z: 'team', max: 9 }]"
  />
</template>
```

::

| Key | Effect |
| --- | --- |
| `x` / `y` | Indicator / value |
| `z` | Series (one polygon per value) |
| `min` / `max` | Scale bounds — by default `0` → `1.2 ×` the largest value |
| `fill` | Colour of each polygon (the palette by default) |
| `opacity` | Opacity of the **filled area** (default `0.18`) |
| `strokeWidth` | Width of the polygon outline |
