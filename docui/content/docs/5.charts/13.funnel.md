**`{ type: 'funnel' }`** draws one slice per row, ordered from the widest to the narrowest: an
acquisition pipeline, a conversion path, a backlog by stage:

::prose-show-case
<dnax-demo-chart demo="funnel"></dnax-demo-chart>

#code

```vue
<template>
  <q-chart
    title="Acquisition funnel"
    :height="280"
    :marks="[
      { type: 'funnel', data: funnelRows, x: 'stage', y: 'value', name: 'Pipeline', labelFormat: 'compact' },
    ]"
  />
</template>
```

::

| Key | Effect |
| --- | --- |
| `x` / `y` | Stage label / value |
| `labels` | `false` hides the labels; `labelPosition` moves them (`inside`, `left`, `right`…) |
| `labelFormat` | Format of the values inside the labels (`compact`, `percent`…) |
| `fill` | One colour per slice — a token or a channel |
| `opacity` | Opacity of the slices |
