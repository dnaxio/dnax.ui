**`{ type: 'histogram' }`** bins a list of values and draws one bar per bin. No aggregation step
is needed: `bins` and `domain` drive the computation, and the bin labels become the category axis:

::prose-show-case
<dnax-demo-chart demo="histogram"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
// 48 values, deterministic
const ages = Array.from({ length: 48 }, (_, i) => 18 + ((i * 7) % 30))
</script>

<template>
  <q-chart
    title="Age distribution"
    :height="280"
    :x="{ label: 'Age' }"
    :y="{ label: 'People' }"
    :marks="[{ type: 'histogram', data: ages, x: (d) => d, bins: 8, fill: 'chart-2', name: 'Ages' }]"
  />
</template>
```

::

| Key | Effect |
| --- | --- |
| `x` | Channel of the values (the row itself for a plain list) |
| `bins` | Number of bins (default `ceil(sqrt(n))`, capped at 40) |
| `domain` | Forced `[min, max]` — values outside are clamped into the first / last bin |
| `labels` | Prints the count inside / above the bars |
| `labelFormat` | Format of the counts |

The last bin is **inclusive** on its upper bound, so the maximum value is always counted once.
The binning helpers are exported (`histogram`, `boxStats`, `linearFit`, `waterfallSteps`) if you
need the same numbers outside a chart.
