**`{ type: 'pie' }`** draws **one slice per row** — `x` is the label of the slice and `y` its
value (the same mapping as `bar`, but a slice instead of a bar). Give `innerRadius` and it
becomes a **donut**:

::prose-show-case
<dnax-demo-chart demo="pie"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const share = [
  { channel: "Online", revenue: 62 },
  { channel: "Store", revenue: 41 },
  { channel: "Partners", revenue: 27 },
  { channel: "Other", revenue: 12 },
]
</script>

<template>
  <!-- 1. No `radius`: the default pie (70 % of the container) -->
  <q-chart
    :height="230"
    :marks="[
      { type: 'pie', data: share, x: 'channel', y: 'revenue', labels: 'name-percent', name: 'Revenue' },
    ]"
  />

  <!-- 2. `radius` as a percentage: the same pie, more compact -->
  <q-chart
    :height="230"
    :marks="[
      { type: 'pie', data: share, x: 'channel', y: 'revenue', radius: '45%', labels: 'percent' },
    ]"
  />

  <!-- 3. `radius` in pixels + `innerRadius`: a 180 px donut -->
  <q-chart
    :height="230"
    :marks="[
      {
        type: 'pie',
        data: share,
        x: 'channel',
        y: 'revenue',
        radius: 90,
        innerRadius: 55,
        labels: false,
      },
    ]"
  />
```

::

### Position — off the axes

A pie is **not laid out on the axes**: the mark brings no `grid`, no `xAxis`, no `yAxis`
(they only appear when a `line`, a `bar` or a `dot` shares the chart). `x` is the slice
label and `y` its value; `orientation`, `z` and `stack` do not apply — there is exactly one
series, and one slice per row.

Slices are ordered as the data is: sort the rows beforehand if the order matters.

### Radius — pie and donut

| Key | Effect |
| --- | --- |
| `radius` | Outer radius — a number (pixels) or a CSS length. `70%` by default. |
| `innerRadius` | Inner radius. Given, the chart becomes a **donut** (`radius: ['50%', '75%']` under the hood). |
| `startAngle` | Starting angle in degrees — `90` (the default) starts at 12 o'clock, angles growing counter-clockwise. |

```ts
{ type: 'pie', data: rows, x: 'label', y: 'value' }                                  // pie, 70 % by default
{ type: 'pie', data: rows, x: 'label', y: 'value', radius: '45%' }                   // more compact
{ type: 'pie', data: rows, x: 'label', y: 'value', radius: 90 }                      // 90 px radius
{ type: 'pie', data: rows, x: 'label', y: 'value', innerRadius: '50%' }              // donut
{ type: 'pie', data: rows, x: 'label', y: 'value', radius: 90, innerRadius: 55 }     // 180 px donut
{ type: 'pie', data: rows, x: 'label', y: 'value', startAngle: 180 }                 // starts at 9 o'clock
```

The demo above shows three of them — no `radius`, a percentage radius and a pixel radius
with an inner radius.

### Labels

`labels` picks what the slice labels show — they are drawn **outside** the pie, with a
leader line, and coloured like their slice:

| `labels` | Rendered |
| --- | --- |
| `name` *(default)* | The slice label (`{b}`) |
| `value` | The value (`{c}`) |
| `percent` | The slice's share of the total (`{d}%`) |
| `name-value` | `Online: 62` |
| `name-percent` | `Online 43.7%` |
| `false` | No label, no leader line |

With many slices the labels overlap — the ones that do not fit are hidden; use
`labels: false` and keep the tooltip alone if it gets crowded.

### Colour

Without `fill`, the slices take the **series palette** (`--chart-1…6`), one after the other.
`fill` colours them:

```ts
{ type: 'pie', data: rows, x: 'label', y: 'value', fill: ['primary', 'chart-2', 'chart-3'] }
{ type: 'pie', data: rows, x: 'label', y: 'value', fill: 'region' }   // a channel: one colour per row
```

A **constant** `fill` gives every slice the same colour — use a channel (a field, values, or
an accessor) for one colour per slice. `opacity` applies to all of them.

### Tooltips and legend

With `title`, hovering a slice shows that value (a token, a field, an accessor…).
A pie is a chart of its own: slices are hovered one by one (never as an axis). Give the mark
a `name` and the **legend lists the slices**, as on the [Bar](/docs/charts/bar) page.
