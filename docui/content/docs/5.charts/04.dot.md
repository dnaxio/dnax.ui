**`{ type: 'dot' }`** draws **one point per row**: that is a scatter plot, and with `r`
as a channel it becomes a **bubble chart**. Both axes are *value* axes (there is no
category), the tooltip is per point, and dots can carry an outline:

::prose-show-case
<dnax-demo-chart demo="dot"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const campaigns = [
  { campaign: "Outlet", spend: 8, revenue: 19, orders: 5 },
  { campaign: "Spring", spend: 12, revenue: 30, orders: 8 },
  { campaign: "Autumn", spend: 17, revenue: 41, orders: 11 },
  { campaign: "Summer", spend: 21, revenue: 48, orders: 14 },
  { campaign: "Winter", spend: 29, revenue: 62, orders: 19 },
]
</script>

<template>
  <q-chart
    title="Revenue vs ad spend"
    :height="260"
    :x="{ label: 'Ad spend (k€)' }"
    :y="{ label: 'Revenue (k€)' }"
    :marks="[
      {
        type: 'dot',
        data: campaigns,
        x: 'spend',
        y: 'revenue',
        r: 'orders',
        fill: 'chart-1',
        stroke: '#fff',
        strokeWidth: 2,
        title: 'campaign',
      },
    ]"
  />
</template>
```

::

### Radius — bubbles

`r` is the radius: a number gives uniform dots, a **channel** gives one size per point
(a bubble chart). The point diameter is `r * 2 + 2` pixels.

```ts
{ type: 'dot', data: rows, x: 'spend', y: 'revenue', r: 4 }          // uniform
{ type: 'dot', data: rows, x: 'spend', y: 'revenue', r: 'orders' }   // bubbles
{ type: 'dot', data: rows, x: 'spend', y: 'revenue', r: (d) => d.orders ** 0.5 }
```

### Colour and outline

| Key | Effect |
| --- | --- |
| `fill` | Fills the dots. |
| `stroke` + `strokeWidth` | Draws an **outline** around them — the usual trick to keep overlapping dots readable. Used when `fill` is given too; a lone `stroke` colours the dots. |
| `opacity` | Applies to the whole dot. |

### Shape

`symbol` picks the marker shape: `circle` (default), `rect`, `roundRect`, `triangle`,
`diamond`, `pin`, `arrow`, `none`… It applies to the whole mark.

### Tooltips

With `title`, hovering a dot shows **that value** — give it a field name, explicit values or
an accessor. Declaring a `title` is also what keeps the tooltip per point: a dot chart
**without** a `title` is cartesian like any other, so it shares the axis tooltip (the
cursor follows the month) exactly as on the [Line](</docs/charts/line>) page.

### A trend line

A scatter is a `dot` mark on two value axes — a **regression line** is then just a second `line`
mark drawn over it. Nothing is built in: fit the points yourself (least squares, a moving
average…) and hand the `line` its two ends:

```ts
const trend = [
  { spend: minX, revenue: slope * minX + intercept },
  { spend: maxX, revenue: slope * maxX + intercept },
]
```

Adding a `line` turns the tooltip into an **axis** tooltip (the cursor follows `x`), so the dots'
own `title` is not used — label the two series with `name` instead. The line keeps a small marker
at each of its ends.

#code

```vue
<script setup lang="ts">
// 24 points déterministes autour d'une tendance : revenue ≈ 3.2 × spend + 12
const noise = (n: number) => {
  let x = (n * 2654435761) % 4294967296
  x = ((x ^ (x >>> 13)) * 1597334677) % 4294967296
  return (x >>> 0) % 100
}
const scatter = Array.from({ length: 24 }, (_, i) => {
  const spend = 2 + i * 1.1
  const jitter = ((noise(i) - 50) / 50) * 4.5 // -4.5 → 4.5
  return { spend: Math.round(spend * 10) / 10, revenue: Math.round((3.2 * spend + 12 + jitter) * 10) / 10 }
})

// Moindres carrés : pente et ordonnée à l'origine
const meanSpend = scatter.reduce((s, p) => s + p.spend, 0) / scatter.length
const meanRevenue = scatter.reduce((s, p) => s + p.revenue, 0) / scatter.length
const slope =
  scatter.reduce((s, p) => s + (p.spend - meanSpend) * (p.revenue - meanRevenue), 0) /
  scatter.reduce((s, p) => s + (p.spend - meanSpend) ** 2, 0)
const intercept = meanRevenue - slope * meanSpend

// La droite : deux points suffisent à une `line`
const spends = scatter.map((p) => p.spend)
const trend = [
  { spend: Math.min(...spends), revenue: slope * Math.min(...spends) + intercept },
  { spend: Math.max(...spends), revenue: slope * Math.max(...spends) + intercept },
]
</script>

<template>
  <q-chart
    title="Revenue vs spend, with a trend line"
    :height="260"
    :x="{ label: 'Ad spend (k€)', min: 0 }"
    :y="{ label: 'Revenue (k€)', min: 0 }"
    :marks="[
      { type: 'dot', data: scatter, x: 'spend', y: 'revenue', r: 4, fill: 'chart-1', stroke: '#fff', strokeWidth: 1.5, name: 'Stores' },
      { type: 'line', data: trend, x: 'spend', y: 'revenue', stroke: 'primary', strokeWidth: 2, name: 'Trend' },
    ]"
  />
</template>
```
