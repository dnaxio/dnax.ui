**`{ type: 'sankey' }`** shows **flows** between stages. Each row is a link; the nodes are deduced
from the sources and the targets:

::prose-show-case
<dnax-demo-chart demo="sankey"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const flows = [
  { source: 'Visits', target: 'Signups', value: 420 },
  { source: 'Visits', target: 'Bounce', value: 580 },
  { source: 'Signups', target: 'Trials', value: 210 },
  { source: 'Trials', target: 'Paid', value: 96 },
]
</script>

<template>
  <q-chart title="Acquisition flow" :height="300" :marks="[{ type: 'sankey', data: flows }]" />
</template>
```

::

Rows are read with the `source` / `target` / `value` fields by default. Use `x`, `y` and `value`
to map other field names:

```ts
{ type: 'sankey', data: rows, x: 'from', y: 'to', value: 'weight' }
```

| Key | Effect |
| --- | --- |
| `x` / `y` | Source / target fields (default: `source` / `target`) |
| `value` | Link weight (default: `value`) |
| `opacity` | Opacity of the nodes |
| `name` | Legend entry (the links are not listed) |
