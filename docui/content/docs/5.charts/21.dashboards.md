The features below turn `<q-chart>` into a dashboard building block.

## Secondary Y axis

A mark can target the **right** axis with `yAxis: 'right'`; configure that axis with `yRight`.
The classic combo: volumes as bars on the left, a rate as a line on the right.

::prose-show-case
<dnax-demo-chart demo="combo"></dnax-demo-chart>

#code

```vue
<q-chart
  :x="{ type: 'band' }"
  :y="{ label: 'Volume', format: 'compact' }"
  :y-right="{ label: 'Rate', format: 'percent', min: 0, max: 5 }"
  :marks="[
    { type: 'bar', data: traffic, x: 'month', y: 'volume', name: 'Volume' },
    { type: 'line', data: traffic, x: 'month', y: 'rate', yAxis: 'right', name: 'Conversion' },
  ]"
/>
```

::

The right axis only exists when a mark asks for it — a chart without `yAxis: 'right'` keeps a
single axis (and its usual margins).

## 100 % stacks

`stack: 'percent'` normalises each category to 100 %. No manual pipeline: the translator sums the
categories and divides the values. Labels can print the share:

::prose-show-case
<dnax-demo-chart demo="percent"></dnax-demo-chart>

#code

```vue
<q-chart
  :y="{ format: 'percent' }"
  :marks="[
    { type: 'bar', data: channelShare, x: 'month', y: 'value', z: 'channel', stack: 'percent', labels: 'percent' },
  ]"
/>
```

::

A **named** stack (`stack: 'volume'`) groups series without normalising them; `stack: true` is the
plain stack. Percent stacking expects non-negative values.

## Floating bars

`base` gives each bar its **starting point** — a budget/actual range, a floating interval:

```vue
<q-chart
  :marks="[
    { type: 'bar', data: budget, x: 'month', y: 'actual', base: 'planned', name: 'Actual' },
    { type: 'rule', y: [50], stroke: 'chart-5', label: 'Plan' },
  ]"
/>
```

Under the hood the translator emits an **invisible base series** and the visible segment in the
same stack group — ECharts has no `[category, [y0, y1]]` value.

## Loading, empty and error states

Three props, three slots, localised defaults (`fr` / `en` from `QConfigProvider`):

```vue
<q-chart :loading="pending" :error="failure" :marks="marks">
  <template #empty>No sales for this period.</template>
</q-chart>
```

| Prop | Effect |
| --- | --- |
| `loading` | Overlay with `#loading` (default “Loading…”) |
| `error` | `true` → localised message, a string → that message; slot `#error` |
| `empty` | Forces the empty state — otherwise it appears when no mark has data; slot `#empty` |
| `texts` | Overrides the built-in labels (`loading`, `empty`, `error`, `exportCsv`, `total`, `page`…) |

The overlay is drawn **over** the canvas: the chart itself stays mounted, so a resize or a new
option does not lose the instance.

## Compact widgets

`compact` is the mini-widget mode: margins reduced to ~2 px, axis labels, axis lines and the
legend hidden, split lines off — tooltips and colours kept. Turn a grid line back on with
`x.grid` / `y.grid`:

::prose-show-case
<dnax-demo-chart demo="compact"></dnax-demo-chart>

#code

```vue
<q-chart compact :height="120" :marks="[{ type: 'line', data: monthly, x: 'month', y: 'revenue' }]" />
```

::

## Tooltips

```vue
<q-chart :tooltip="{ valueFormatter: (v) => `${v} k€`, sortDesc: true }" :marks="marks" />
```

| Key | Effect |
| --- | --- |
| `valueFormatter` | Formats each value (axis and item tooltips) |
| `nameFormatter` | Formats the series / datum names |
| `formatter` | Full control: receives the ECharts params, returns HTML |
| `sortDesc` | Sorts the axis tooltip rows by value, descending |

A mark can also carry its own `tooltip: (params, value) => string`, which receives the raw value.

::prose-show-case
<dnax-demo-chart demo="tooltip"></dnax-demo-chart>

#code

```vue
<q-chart
  title="Revenue, formatted tooltip"
  :height="280"
  :y="{ format: 'compact' }"
  :tooltip="{ valueFormatter: (value) => `${value} k€`, sortDesc: true }"
  :marks="[
    { type: 'bar', data: monthly, x: 'month', y: 'revenue', name: 'Revenue' },
    { type: 'line', data: monthly, x: 'month', y: 'cost', name: 'Cost' },
  ]"
/>
```

::

## BI table

The `table` mark sorts, paginates, totals and exports — the interactive state lives in the
component (click a header to cycle **asc → desc → none**):

```vue
<q-chart
  exportable
  :height="290"
  :marks="[
    {
      type: 'table',
      data: monthly,
      sortBy: 'revenue',
      sortDesc: true,
      pageSize: 4,
      totals: { label: 'Total' },
      columns: [
        { field: 'month', label: 'Month', width: 110 },
        { field: 'revenue', label: 'Revenue', align: 'end', summary: 'sum' },
        { field: 'cost', label: 'Cost', align: 'end', summary: 'sum' },
      ],
    },
  ]"
/>
```

`summary` accepts `sum`, `avg`, `min`, `max`, `count`. The CSV export contains **all** visible
rows (not just the current page) and follows `separator`, `format` and the totals row.

See [Table](/docs/charts/table) for the columns and separators.
