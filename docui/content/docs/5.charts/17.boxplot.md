**`{ type: 'boxplot' }`** shows the **distribution** of a measure per category: minimum, first
quartile, median, third quartile and maximum. Give the **raw values** and the five numbers are
computed for you — or pass ready-made stats:

::prose-show-case
<dnax-demo-chart demo="boxplot"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const groups = [
  { team: 'Alpha', scores: [62, 68, 71, 74, 79, 83, 88] },
  { team: 'Beta', scores: [55, 61, 65, 67, 70, 74, 80] },
  { team: 'Gamma', scores: [70, 72, 76, 80, 84, 88, 95] },
]
</script>

<template>
  <q-chart
    title="Scores by team"
    :height="280"
    :marks="[{ type: 'boxplot', data: groups, x: 'team', values: 'scores', name: 'Scores' }]"
  />
</template>
```

::

| Key | Effect |
| --- | --- |
| `x` | Category of each box |
| `values` | Channel of the **raw list** — quartiles are computed (R-7, like `QUARTILE.INC`) |
| `stats` | Channel of **precomputed** `[min, q1, median, q3, max]` (wins over `values`) |
| `fill` | Colour of the box (the outline is drawn from `stroke` / `fill`) |
| `strokeWidth` | Width of the outline |
| `yAxis` | `left` *(default)* or `right` |
