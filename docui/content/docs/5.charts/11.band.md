**`{ type: 'band' }`** paints a **zone** behind the other marks: a target range, an alert band,
a confidence interval. It is not a series — nothing is added to the legend — and it sits under the
data, so the bars and lines stay readable:

::prose-show-case
<dnax-demo-chart demo="band"></dnax-demo-chart>

#code

```vue
<template>
  <q-chart
    title="Revenue and target zone"
    :height="280"
    :marks="[
      { type: 'bar', data: monthly, x: 'month', y: 'revenue', fill: 'chart-1', name: 'Revenue', labels: true },
      { type: 'band', y0: 45, y1: 55, fill: 'positive', opacity: 0.14, label: 'Target zone' },
      { type: 'rule', y: [50], stroke: 'chart-5', label: 'Target', labelPosition: 'insideEndTop' },
    ]"
  />
</template>
```

::

## Horizontal — the default

Values sit on the **Y axis** (`y0` → `y1`), which is the usual threshold band:

```ts
{ type: 'band', y0: 45, y1: 55 }
{ type: 'band', y0: 'low', y1: 'high' }   // a channel: one band per row
```

Here `'low'` / `'high'` are read as **fields of each row** — a string that is not a field of the
data is treated as a constant (`y0: 'Draft'` works on a category axis).

## Vertical

Give `x0` / `x1` instead — a value on a value axis, or a category name:

```ts
{ type: 'band', x0: 10, x1: 20 }
{ type: 'band', x0: 'Mar', x1: 'May' }
```

## Styling

| Key | Effect |
| --- | --- |
| `fill` | Colour of the zone — a token (`positive`, `warning`, `chart-4`…) or any CSS color |
| `opacity` | Opacity of the zone (default: the engine's) — `0.08`–`0.18` reads well under bars |
| `label` | Text written inside the band |
| `labelPosition` | `insideTop` *(default)*, `insideBottom`, `insideLeft`, `insideRight`… |
| `stroke` | Border colour of the zone |

A chart made only of bands works too — no series needed.

## Band options

A **`band`** mark takes the options below — it is a `markArea` under the hood, so it carries
positions and a fill, nothing else. Other marks are listed on the [Charts](/docs/charts) overview.
