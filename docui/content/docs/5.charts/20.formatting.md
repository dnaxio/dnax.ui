Every value on a chart can be formatted with the same vocabulary: a **short name**
(`compact`, `percent`, `currency`, `date`…), an **object** (`{ style, locale, currency, … }`) or a
**function** `(value, ctx) => string`. Formatting uses [`Intl`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl) and never peeks at the browser locale:

```vue
<q-chart :locale="'fr-FR'" :y="{ format: 'compact' }" :marks="marks" />
```

`locale` defaults to the **host language** (`fr` → `fr-FR`, otherwise `en-US`). Nothing is
formatted until a `format` is given — without one, values are printed as they are.

## Short formats

| `style` | `1200` becomes (fr-FR) | Notes |
| --- | --- | --- |
| `number` *(default)* | `1 200` | up to 2 decimals |
| `decimal` | `1 200` | same, kept for symmetry with `Intl` |
| `compact` | `1,2 k` | `1 234 567` → `1,2 M` |
| `percent` | — | the value is **already a percentage**: `42` → `42 %` |
| `currency` | `1 200 F CFA` | `currency: 'XOF'` by default (`F CFA`); `EUR`, `USD`… otherwise |
| `date` | `5 mars 2024` | `Date`, timestamp (s or ms) or ISO string |
| `time` | `10:30` | honours `timeZone` |
| `datetime` | `5 mars 2024, 10:30` | date + time |

## Object form

```ts
y: {
  format: {
    style: 'currency',
    currency: 'XOF',
    maximumFractionDigits: 0,
    suffix: ' HT',
  },
}
```

| Key | Effect |
| --- | --- |
| `style` | One of the short formats above |
| `locale` | Overrides the chart locale for this format |
| `currency` | ISO 4217 code (`XOF` → `F CFA`, `EUR` → `€`) |
| `timeZone` | IANA zone (`Africa/Dakar`, `Europe/Paris`) for dates |
| `minimumFractionDigits` / `maximumFractionDigits` | Decimal places |
| `dateStyle` / `timeStyle` | `full`, `long`, `medium`, `short` |
| `prefix` / `suffix` | Text around the formatted value |

## Where it applies

```ts
y: { format: 'compact' }                        // axis ticks
marks: [
  { type: 'bar', labels: true, labelFormat: 'compact' },
  { type: 'line', labels: 'percent', labelFormat: 'percent' },
  { type: 'pie', labels: 'name-percent', labelFormat: 'currency' },
]
tooltip: { valueFormatter: (value) => `${value} k€` }
```

- **Axes** — `x.format` / `y.format` / `yRight.format`, plus `x.timeUnit` (`day`, `week`, `month`,
  `quarter`, `year`) for a temporal axis.
- **Data labels** — `labelFormat` on `bar`, `line`, `area`, `pie`, `funnel`, `heatmap`, `gauge`,
  `histogram`, `waterfall`, `treemap`.
- **Tooltips** — `tooltip.valueFormatter` (or a per-mark `tooltip` function).
- **Tables** — `columns[].format` still receives the raw value and the row; `cell.format`
  formats an in-cell visualisation (bar, delta, sparkline label).

## Functions

```vue
<q-chart :y="{ format: (value) => `${Math.round(value)} pts` }" :marks="marks" />
```

A format function receives `(value, ctx)` where `ctx` carries `{ locale, index, row, name }` — use
it to build composite labels without losing the locale.
