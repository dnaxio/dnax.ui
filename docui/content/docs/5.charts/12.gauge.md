**`{ type: 'gauge' }`** shows a single measure against a scale: uptime, service level, budget
consumption. The arc is split into **performance bands**, the filled progress shows the current
value, and the target is printed under it:

::prose-show-case
<dnax-demo-chart demo="gauge"></dnax-demo-chart>

#code

```vue
<template>
  <q-chart
    title="Service level"
    :height="260"
    :marks="[
      {
        type: 'gauge',
        data: [{ label: 'Uptime', value: 99.2 }],
        x: 'label',
        y: 'value',
        min: 90,
        max: 100,
        target: 99,
        unit: '%',
        bands: [
          { to: 97, color: 'negative' },
          { to: 99, color: 'warning' },
          { to: 100, color: 'positive' },
        ],
      },
    ]"
  />
</template>
```

::

## Keys

| Key | Effect |
| --- | --- |
| `x` / `y` | Label and value of the measure (the first row is used) |
| `min` / `max` | Scale bounds (default `0` → `100`) |
| `bands` | Performance ranges: `{ to, color }`, `to` in **axis units** (or `fraction: true` for `0`→`1`) |
| `target` | Target value, printed under the current value (`Cible 99 %`) |
| `unit` | Suffix of the displayed value (`%`, `F CFA`…) |
| `radius` | Outer radius (number = pixels, or a CSS length — default `75%`) |
| `fill` | Colour of the progress arc |
| `labelFormat` | Format of the numbers (`percent`, `compact`, `currency`…) |

A **bullet chart** is the horizontal variant of the same idea: a `bar` with `base`, a `band` for
the performance ranges and a `rule` for the target. See [Bar](/docs/charts/bar) and
[Band](/docs/charts/band).
