**`<q-chart>`** with `{ type: 'bar' }` marks. The **`z`** channel splits the rows into
one series per value (each with a legend entry) and `stack` piles them up — no need to
reshape the data:

::prose-show-case
<dnax-demo-chart demo="bar"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const months = ["Jan", "Feb", "Mar", "Apr"]
const sales = months.flatMap((month, i) => [
  { month, channel: "Online", value: 20 + ((i * 7) % 23) },
  { month, channel: "Store", value: 12 + ((i * 5) % 17) },
])
</script>

<template>
  <q-chart
    title="Sales per channel"
    :height="260"
    :marks="[{ type: 'bar', data: sales, x: 'month', y: 'value', z: 'channel', stack: true }]"
  />
</template>
```

::

Without `stack`, the same mark renders **grouped** bars. With no explicit color, each
series takes the next entry of the `--chart-N` palette (see
[Line](</docs/charts/line>)). For **horizontal** bars, keep the channels as they are and
add `orientation: 'horizontal'`:

```vue
<q-chart :marks="[{ type: 'bar', data: sales, x: 'month', y: 'value', orientation: 'horizontal' }]" />
```

### 100 % stacks

`stack: 'percent'` normalises each category to 100 %; `labels: 'percent'` prints the share and
`y: { format: 'percent' }` formats the axis:

```ts
{ type: 'bar', data: sales, x: 'month', y: 'value', z: 'channel', stack: 'percent', labels: 'percent' }
```

A **named** stack (`stack: 'volume'`) groups series without normalising. See
[Dashboards](/docs/charts/dashboards).

### Floating bars

`base` gives every bar its **starting point** — budget vs actual, ranges, bullet charts:

```ts
{ type: 'bar', data: budget, x: 'month', y: 'actual', base: 'planned' }
```

::prose-show-case
<dnax-demo-chart demo="float"></dnax-demo-chart>

#code

```vue
<q-chart
  title="Budget vs actual"
  :height="280"
  :marks="[
    { type: 'bar', data: budget, x: 'month', y: 'actual', base: 'planned', fill: 'chart-2', name: 'Actual', labels: true },
    { type: 'rule', y: [50], stroke: 'chart-5', label: 'Plan', labelPosition: 'insideEndTop' },
  ]"
/>
```

::

### Labels, thresholds, secondary axis

```ts
{ type: 'bar', data: rows, x: 'month', y: 'value', labels: true, labelFormat: 'compact' }
{ type: 'bar', data: rows, x: 'month', y: 'score', thresholds: [{ value: 80, op: 'gte', color: 'positive' }] }
{ type: 'bar', data: rows, x: 'month', y: 'volume', yAxis: 'right' }
```

::prose-show-case
<dnax-demo-chart demo="labels"></dnax-demo-chart>

#code

```vue
<q-chart
  title="Revenue, with data labels"
  :height="280"
  :y="{ format: 'compact' }"
  :marks="[
    { type: 'bar', data: monthly, x: 'month', y: 'revenue', name: 'Revenue', labels: true, labelFormat: 'compact' },
    { type: 'line', data: monthly, x: 'month', y: 'cost', name: 'Cost', labels: 'percent', labelPosition: 'bottom' },
  ]"
/>
```

::

**Declarative colours** — `thresholds` is the first rule that matches, evaluated per point:

::prose-show-case

#code

```vue
<script setup lang="ts">
const thresholds = [
  { value: 80, op: 'gte', color: 'positive' },
  { value: 60, op: 'gte', color: 'warning' },
  { value: 0, op: 'gte', color: 'negative' },
]
</script>

<template>
  <q-chart
    title="Weekly score"
    :height="280"
    :y="{ min: 0, max: 100 }"
    :marks="[{ type: 'bar', data: scores, x: 'week', y: 'score', thresholds, labels: true }]"
  />
</template>
```
