**`{ type: 'heatmap' }`** draws **one cell per row**: `x` is the column, `y` the row — both
are **category axes** — and `fill` is the **value** of the cell, mapped to a colour scale
(just like the `fill` of a Plot rectangle):

#code

```vue
<script setup lang="ts">
const temps = [
  { day: "Mon", hour: "9h", temp: 12 },
  { day: "Mon", hour: "13h", temp: 21 },
  { day: "Mon", hour: "17h", temp: 19 },
  { day: "Tue", hour: "9h", temp: 8 },
  { day: "Tue", hour: "13h", temp: 18 },
  { day: "Tue", hour: "17h", temp: 23 },
  { day: "Wed", hour: "9h", temp: 14 },
  { day: "Wed", hour: "13h", temp: 26 },
  { day: "Wed", hour: "17h", temp: 30 },
  { day: "Thu", hour: "9h", temp: 10 },
  { day: "Thu", hour: "13h", temp: 24 },
  { day: "Thu", hour: "17h", temp: 27 },
]

// Échappatoire : la clé `visualMap` passée dans `options` remplace celle émise par la marque
const heatScale = {
  visualMap: [
    {
      min: 0,
      max: 35,
      calculable: true,
      inRange: { color: ["#dbeafe", "#1d4ed8"] },
      orient: "horizontal",
      left: 0,
      bottom: 0,
      itemWidth: 12,
      itemHeight: 100,
    },
  ],
}
</script>

<template>
  <!-- 1. `fill` numérique : la rampe de couleurs (palette des séries), valeur imprimée -->
  <q-chart
    title="Temperature by hour"
    :height="230"
    :x="{ label: 'Hour' }"
    :y="{ label: 'Day' }"
    :marks="[
      { type: 'heatmap', data: temps, x: 'hour', y: 'day', fill: 'temp', labels: true, name: 'Temperature' },
    ]"
  />

  <!-- 2. `fill` constant : une grille unie — l'échelle disparaît, la valeur passe en info-bulle -->
  <q-chart
    title="Booked slots"
    :height="230"
    :x="{ label: 'Hour' }"
    :y="{ label: 'Day' }"
    :marks="[
      { type: 'heatmap', data: temps, x: 'hour', y: 'day', fill: 'primary', title: (d) => `${d.temp} °C`, name: 'Slot' },
    ]"
  />

  <!-- 3. Échelle personnalisée : `visualMap` via l'échappatoire `options` -->
  <q-chart
    title="Temperature, custom scale"
    :height="250"
    :x="{ label: 'Hour' }"
    :y="{ label: 'Day' }"
    :marks="[{ type: 'heatmap', data: temps, x: 'hour', y: 'day', fill: 'temp', name: 'Temperature' }]"
    :options="heatScale"
  />
</template>
```

::

The demo runs three variants of the same grid — the value ramp (`fill: 'temp'`), a constant
colour, and a custom scale.

### A grid of categories — both axes

A heat map uses **both axes as categories**: the columns come from `x`, the rows from `y`,
each in the order the data is read (sort the rows beforehand if the order matters). The
cells are then laid out automatically, one per `(column, row)` pair.

Two consequences:

- the axes of `<q-chart>` are **replaced** by those categories — giving `x` / `y` a
  `label` still works, but a `type` (`linear`, `time`…) is ignored;
- a heat map **cannot share a chart** with a `line`, a `bar` or a `dot`: those need a value
  axis, which a heat map takes over. Use one chart per heat map.

### The value — `fill`

`fill` holds the cell value, as a channel (a field, explicit values, or an accessor):

```ts
{ type: 'heatmap', data: rows, x: 'hour', y: 'day', fill: 'temp' }        // a field
{ type: 'heatmap', data: rows, x: 'hour', y: 'day', fill: (d) => d.c - 273 }  // an accessor
```

Numbers are mapped to a **colour ramp**: the series palette (`colors`, i.e. `--chart-1…6`)
between the smallest and the largest value of the mark. A **colour** instead of a number
(a token like `primary`, or any CSS colour) paints every cell that colour — handy for a
plain grid, or to layer your own encoding on top.

The scale itself is emitted by the mark (`visualMap`): it is drawn under the chart, with the
minimum and the maximum on each side. For a custom ramp, a different position, or a range
selector, pass your own through the escape hatch — it **replaces** the emitted one (the merge
is shallow, key by key), so carry the layout with it:

```vue
<q-chart
  :marks="[{ type: 'heatmap', data: rows, x: 'hour', y: 'day', fill: 'temp' }]"
  :options="{
    visualMap: [{
      min: 0, max: 40, calculable: true,
      inRange: { color: ['#fff', '#c10015'] },
      orient: 'horizontal', left: 0, bottom: 0, itemWidth: 12, itemHeight: 100,
    }],
  }"
/>
```

Given a constant colour there is nothing to scale, so the `visualMap` is emitted **hidden**
and the cells keep that colour.

### Labels and tooltips

| Key | Effect |
| --- | --- |
| `labels: true` | Prints the value **inside** each cell. |
| `title` | Per-cell tooltip — a channel, to replace the default. |
| `opacity` | Applies to the whole grid. |
| `name` | Series name (legend entry and tooltip). |

`title` sets the **tooltip** of a cell — a channel of your own (the raw temperature, a
formatted date, a label…). A chart made of a heat map
alone is hovered cell by cell — never as an axis.

### A contribution calendar

Rows are the **days**, columns the **weeks** — one cell per day, its colour the number of
contributions. The scale is **discrete** (five steps, as on a contribution graph), which a
`piecewise` `visualMap` gives you — the mark's own scale is a continuous ramp. Each cell carries
its own tooltip through `title` ("3 contributions · Tue, Jan 7"), and the columns are labelled
with their week start (the axis drops the labels that would overlap). Clicking a step of the
scale filters the chart.

#code

```vue
<script setup lang="ts">
// 20 semaines × 7 jours — données déterministes (hash entier), identiques serveur/client
const DAYS = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
const MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
const noise = (n: number) => {
  let x = (n * 2654435761) % 4294967296
  x = ((x ^ (x >>> 13)) * 1597334677) % 4294967296
  return (x >>> 0) % 100
}
const start = Date.UTC(2025, 0, 6) // lundi 6 janvier 2025
const label = (ms: number) => {
  const date = new Date(ms)
  return `${MONTHS[date.getUTCMonth()]} ${date.getUTCDate()}`
}
const contributions = Array.from({ length: 20 }).flatMap((_, w) =>
  DAYS.map((day, d) => {
    const ms = start + (w * 7 + d) * 864e5
    const n = noise(w * 7 + d)
    const quiet = n < 26 || (d >= 5 && n < 62) // week-ends plus calmes
    const count = quiet ? 0 : n < 52 ? 1 + (n % 3) : n < 78 ? 4 + (n % 3) : n < 92 ? 7 + (n % 3) : 10 + (n % 6)
    return { week: label(start + w * 7 * 864e5), day, date: label(ms), count }
  }),
)

// Échelle **discrète** (5 paliers), à la GitHub — échappatoire `options.visualMap`
const calendar = {
  visualMap: [
    {
      type: "piecewise",
      pieces: [
        { min: 0, max: 0, color: "#ebedf0" },
        { min: 1, max: 3, color: "#9be9a8" },
        { min: 4, max: 6, color: "#40c463" },
        { min: 7, max: 9, color: "#30a14e" },
        { min: 10, color: "#216e39" },
      ],
      orient: "horizontal",
      left: 0,
      bottom: 0,
      itemWidth: 12,
      itemHeight: 12,
      itemSymbol: "roundRect",
      text: ["Less", "More"],
    },
  ],
}
</script>

<template>
  <q-chart
    title="Contributions"
    :height="280"
    :x="{ label: 'Week' }"
    :y="{ label: 'Day' }"
    :marks="[
      {
        type: 'heatmap',
        data: contributions,
        x: 'week',
        y: 'day',
        fill: 'count',
        title: (d) => `${d.count} contributions · ${d.day}, ${d.date}`,
      },
    ]"
    :options="calendar"
  />
</template>
```
