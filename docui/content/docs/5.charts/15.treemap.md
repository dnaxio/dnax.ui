**`{ type: 'treemap' }`** turns a **hierarchy** into nested areas, each sized by its value:
spend by department, storage by folder, revenue by region. Name the node with `x`, its parent
with `parent` and its weight with `value`:

::prose-show-case
<dnax-demo-chart demo="treemap"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const spend = [
  { name: 'Product', parent: '', value: 0 },
  { name: 'Engineering', parent: 'Product', value: 42 },
  { name: 'Design', parent: 'Product', value: 18 },
  { name: 'Marketing', parent: '', value: 0 },
  { name: 'Ads', parent: 'Marketing', value: 26 },
  { name: 'Content', parent: 'Marketing', value: 14 },
]
</script>

<template>
  <q-chart
    title="Spend by department"
    :height="300"
    :marks="[{ type: 'treemap', data: spend, x: 'name', parent: 'parent', value: 'value', name: 'Spend' }]"
  />
</template>
```

::

Rows without a parent (or whose parent is not in the data) become roots. A root may carry
children **and** no value — its area is then the sum of its children.

::prose-callout{variant="note"}
**Names are unique keys.** Two rows with the same `name` are the same node, so a leaf and its
parent must not share a name.
::

`{ type: 'sunburst' }` takes the **same** keys and renders the hierarchy as concentric rings
(`radius: ['15%', '90%']` by default).

## Sunburst

Same data, same keys — the levels become **rings** instead of nested rectangles:

::prose-show-case
<dnax-demo-chart demo="sunburst"></dnax-demo-chart>

#code

```vue
<q-chart
  title="Spend by department"
  :height="300"
  :marks="[{ type: 'sunburst', data: spend, x: 'name', parent: 'parent', value: 'value', name: 'Spend' }]"
/>
```
