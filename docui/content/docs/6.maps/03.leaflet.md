`provider="leaflet"` renders the map with **[Leaflet](https://leafletjs.com/)** — the
classic raster engine: no key, no account, any XYZ tile source. It is lighter than the
MapTiler SDK and needs no WebGL, which makes it the right choice for a small map inside a
big page, or for a project that already uses Leaflet.

::prose-show-case
:dnax-demo-map{demo="leaflet"}

#code

```vue
<script setup lang="ts">
const marks = [
  { type: "marker", position: [2.2945, 48.8584], label: "Tour Eiffel", color: "primary", open: true },
  { type: "popup", position: [2.3376, 48.8606], label: "Le Louvre", open: true },
]
</script>

<template>
  <q-map provider="leaflet" center="[2.3522, 48.8566]" :zoom="12" :marks="marks" />
</template>
```
::

## The `[lat, lng]` trap

Leaflet is the only engine working in **`[lat, lng]`** order. dnax.ui keeps its
`[lng, lat]` convention everywhere — `center`, `marks[].position`, `@pick` — and the
engine does the conversion. Nothing to write yourself, but it is what to look at when
comparing with a Leaflet sample copied from elsewhere: a map centred on the wrong place
is almost always a swapped pair.

## Tiles

`tiles` sets the XYZ template, `attribution` the credit line — both default to the public
OpenStreetMap layer:

```vue
<q-map
  provider="leaflet"
  tiles="https://tuiles.example/{z}/{x}/{y}.png"
  attribution="© Mon fournisseur"
  :options="{ tileLayer: { maxZoom: 18, detectRetina: true } }"
/>
```

Even with the default tiles, keep the attribution visible: it is required by the
OpenStreetMap tile usage policy (see
[OpenStreetMap](/docs/maps/openstreetmap) for the details and the traffic limits).

## Options

`options` goes to `L.map()` (`zoomControl`, `minZoom`, `maxZoom`, `scrollWheelZoom`,
`dragging`, `preferCanvas`…), and its `tileLayer` key to `L.tileLayer()`. `<q-map>` only
imposes the container element:

```vue
<q-map provider="leaflet" :options="{ zoomControl: false, maxZoom: 18 }" />
```

## Marks

The same `marks` API as every provider: `marker` and `popup`, with the same `label` /
`html`, `color`, `open`, `offset` and `draggable` keys. The pins are drawn as **SVG**
(`divIcon`), so `color` takes a dnax token (`primary`, `chart-2`…) or any CSS colour —
Leaflet's default icon is a bitmap image and cannot be recoloured.

## What Leaflet does not do

The vector layer is MapTiler-only: `map-style`, `terrain` and `projection` have no effect
here, `navigation` / `geolocate` / `scale` / `fullscreen` are the SDK's controls and are
ignored too (Leaflet ships its own zoom control, and its plugins are added through the
exposed instance), and the raster tiles do not follow the app's dark mode.

```vue
<q-map ref="map" provider="leaflet" … @ready="(instance) => (leaflet = instance)" />

<script setup lang="ts">
// l'instance exposée est le L.Map : les plugins Leaflet s'y branchent tels quels
const leaflet = ref()
const locate = () => leaflet.value.locate({ setView: true })
</script>
```
