`provider="openstreetmap"` renders the classic **OpenStreetMap raster** layer: no key, no
account, no session counting. It is also the automatic fallback when
`provider="maptiler"` has no key (with a console warning) — the frame is never left empty.

::prose-show-case
:dnax-demo-map{demo="openstreetmap"}

#code

```vue
<template>
  <q-map provider="openstreetmap" center="[2.3522, 48.8566]" :zoom="11.5" :marks="marks" />
</template>
```
::

`osm` and `openstreet` are accepted as aliases of `openstreetmap`, and any unknown value
falls back to `maptiler` with a console warning.

The style used is a small raster style, defined in `lib/map.ts`:

```ts
{ version: 8,
  sources: { osm: { type: "raster", tiles: ["https://tile.openstreetmap.org/{z}/{x}/{y}.png"] } },
  layers: [{ id: "osm", type: "raster", source: "osm" }] }
```

## What you give up

The whole MapTiler layer is MapTiler-only: the `map-style` shorthand names (and their dark
variants — the raster is a fixed light map, it does not follow the app theme), `terrain`,
`projection="globe"`, the satellite/hybrid styles, the client APIs (geocoding, static
maps, elevation). What still works is everything `dnax.ui` brings to the component:
`center`, `zoom`, `marks` (coloured pins, popups, `@pick`), the controls, `options` —
and any style object passed through `options.style`.

```vue
<q-map provider="openstreetmap" :options="{ style: myOwnStyleObject }" />
```

Or simply give your own raster source with `tiles` / `attribution` — the same props drive
the [Leaflet](/docs/maps/leaflet) provider:

```vue
<q-map
  provider="openstreetmap"
  tiles="https://tuiles.example/{z}/{x}/{y}.png"
  attribution="© Mon fournisseur"
/>
```

## Attribution & usage

The OpenStreetMap attribution rendered by the map must stay visible (the SDK adds it from
the style). The public tile service is meant for **light, demo-level traffic**: for a real
application, either point `options.style` at your own tiles or switch to
`provider="maptiler"` (see [MapTiler](/docs/maps/maptiler)) — the raster tiles are also
heavier than the vector styles.
