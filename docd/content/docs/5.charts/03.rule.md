**`{ type: 'rule' }`** draws a **reference line**: a target, a threshold, a zero baseline.
It is not a series — nothing is added to the legend — and it is painted over the other
marks, so it reads as an annotation rather than as data:

::prose-show-case
<dnax-demo-chart demo="rule"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const monthly = [
  { month: "Jan", revenue: 42 },
  { month: "Feb", revenue: 51 },
  { month: "Mar", revenue: 47 },
  { month: "Apr", revenue: 63 },
]
</script>

<template>
  <q-chart
    title="Sales vs target"
    :height="260"
    :marks="[
      { type: 'bar', data: monthly, x: 'month', y: 'revenue', fill: 'chart-1', name: 'Revenue' },
      { type: 'rule', y: [50], stroke: 'chart-5' },
      { type: 'rule', x: ['Apr'], stroke: 'negative', strokeWidth: 2 },
    ]"
  />
</template>
```

::

### Horizontal — the default

Values sit on the **Y axis**, so this is the plain “target line”:

```ts
{ type: 'rule', y: 50 }              // a single line
{ type: 'rule', y: [0, 25, 50] }     // one line per value
{ type: 'rule', data: [0, 25, 50] }  // same, values in `data`
```

### Vertical

Give `x` instead of `y` — a value on a value axis, or a **category name** on a category
axis (it lands on that category):

```ts
{ type: 'rule', x: [0] }
{ type: 'rule', x: ['Apr'] }
```

### Styling

| Key           | Effect                                                                        |
| ------------- | ----------------------------------------------------------------------------- |
| `stroke`      | Line colour — a token (`chart-5`, `negative`, `primary`…) or any CSS color. Defaults to the grid colour (`--border`). `fill` is accepted as a fallback. |
| `strokeWidth` | Line width.                                                                    |
| ignored       | `name`, `title`, `text`, `r`, `opacity`, `z`, `stack` — a rule is a single line, not a series. |

The line is **dashed** by default, which is what makes it read as a reference rather than
as another series. A chart made only of rules works too — no series needed.

Marks, channels and the axis/format props are listed on the
[Line](</docs/charts/line>) page — every page uses the same `q-chart`.

## Rule options

A **`rule`** mark takes the options below — it is a `markLine` under the hood, so it only
