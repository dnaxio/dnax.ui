**`{ type: 'image' }`** draws an **image centered on `x` and `y`**: the same idea as a dot
mark, but each point is a picture — portraits, flags, logos, maps. `src` is required and
the default size is 16×16 pixels:

::prose-show-case
<dnax-demo-chart demo="image"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
// One Unsplash id per person; imgix returns a 200×200 square centred on the face.
const photo = (id: string) =>
  `https://images.unsplash.com/${id}?q=80&w=200&h=200&fit=crop&crop=faces&auto=format`

const team = [
  { name: "Amina", experience: 3, score: 4.6, src: photo("photo-1502323777036-f29e3972d82f") },
  { name: "Bastien", experience: 6, score: 4.2, src: photo("photo-1611590027211-b954fd027b51") },
  { name: "Chloé", experience: 2, score: 4.8, src: photo("photo-1753381449444-9fe1d1cf5b5b") },
  {
    name: "Dan",
    experience: 9,
    score: 3.9,
    src: "https://plus.unsplash.com/premium_photo-1714340726276-5f6897ddc3ca?q=80&w=200&h=200&fit=crop&crop=faces&auto=format",
  },
  { name: "Elif", experience: 5, score: 4.4, src: photo("photo-1568579569464-f87941549e29") },
]
</script>

<template>
  <q-chart
    title="Team"
    :height="260"
    :x="{ label: 'Experience (years)', min: 0 }"
    :y="{ label: 'Review score', min: 3 }"
    :marks="[
      { type: 'image', data: team, x: 'experience', y: 'score', src: 'src', r: 22, title: 'name' },
    ]"
  />
</template>
```

::

### `src`

`src` is the image of each point. A string starting with `.`, `/` or a protocol is taken
as a **constant** (`src: 'https://…'` or `src: '/logo.svg'`); anything else is read as a
**channel**, i.e. a field of each row:

```ts
{ type: 'image', data: team, x: 'experience', y: 'score', src: 'src' }   // one photo per row
{ type: 'image', data: rows, x: 'x', y: 'y', src: '/logo.svg' }          // the same logo for all
```

Any URL the browser can load works — `https://…`, a relative path, an object URL, a
`data:` URI.

### Size

| Key | Effect |
| --- | --- |
| `width` / `height` | Image size in pixels — constant or channel. Give only one and the other follows it. |
| `r` | Shorthand for a **square** of `2r × 2r` pixels. |
| `rotate` | Rotation in degrees, clockwise. |

The aspect ratio is preserved: the image is fitted inside the box rather than stretched,
so **serve a square crop** when the box is square (Unsplash/imgix: `&w=200&h=200&fit=crop`),
otherwise the picture is letterboxed. A size of `0` (or less) hides the image. `image://`
does **not** clip the image — for round markers use `round: true`, just below.

### Round markers

`round: true` paints the image **inside a circle** instead of drawing it as a square symbol —
the avatar look, with an optional ring around it:

::prose-show-case
<dnax-demo-chart demo="image-round"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
// Serve the picture **at the marker size**: the image is painted as a pattern at its own
// size, anchored at the top-left of the marker, so a bigger source would be cropped.
const avatar = (id: string) =>
  `https://images.unsplash.com/${id}?q=80&w=44&h=44&fit=crop&crop=faces&auto=format`

const team = [
  { name: "Amina", experience: 3, score: 4.6, src: avatar("photo-1502323777036-f29e3972d82f") },
  { name: "Bastien", experience: 6, score: 4.2, src: avatar("photo-1611590027211-b954fd027b51") },
  { name: "Chloé", experience: 2, score: 4.8, src: avatar("photo-1753381449444-9fe1d1cf5b5b") },
  { name: "Dan", experience: 9, score: 3.9, src: avatar("photo-…premium…") },
  { name: "Elif", experience: 5, score: 4.4, src: avatar("photo-1568579569464-f87941549e29") },
]
</script>

<template>
  <q-chart
    title="Team"
    :height="260"
    :x="{ label: 'Experience (years)', min: 0 }"
    :y="{ label: 'Review score', min: 3 }"
    :marks="[
      {
        type: 'image',
        data: team,
        x: 'experience',
        y: 'score',
        src: 'src',
        r: 22,
        round: true,
        stroke: 'primary',
        strokeWidth: 2,
        title: 'name',
      },
    ]"
  />
</template>
```

::

An image cannot be clipped to a shape (`image://` stays square), so `round: true` uses the one
approach that works: a **pattern fill** painted inside a `circle` symbol. Two things to know:

| | |
| --- | --- |
| **Serve the image at the marker size** | the pattern is painted at the image's own size, anchored at the marker's top-left corner — a 200 px photo in a 44 px circle shows its top-left 44 px. Resize on the fly (`&w=44&h=44&fit=crop`) and keep it **square**. |
| The marker stays a **box** | `r` (or `width` / `height`) sizes that box; an unsquare box becomes an ellipse. |

`stroke` + `strokeWidth` draw the **ring** around the circle (2 px by default); `opacity`,
`title` and `rotate` behave as for a plain image.

Images are loaded **asynchronously**: on the first paint the boxes can be empty for a few
frames. They are drawn in input order — sort the data if overlapping images must be
layered a certain way.

Marks, channels and the axis/format props are listed on the
[Line](</docs/charts/line>) page — every page uses the same `q-chart`.
