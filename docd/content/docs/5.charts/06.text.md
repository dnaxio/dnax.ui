**`{ type: 'text' }`** draws **one label per row** at `x` and `y`. It is mostly used to
label another mark — the value on top of a bar, a year along a line — because direct
labelling reads faster than an axis or a tooltip:

::prose-show-case
<dnax-demo-chart demo="text"></dnax-demo-chart>

#code

```vue
<script setup lang="ts">
const monthly = [
  { month: "Jan", revenue: 42, cost: 28 },
  { month: "Feb", revenue: 51, cost: 31 },
  { month: "Mar", revenue: 47, cost: 30 },
  { month: "Apr", revenue: 63, cost: 35 },
  { month: "May", revenue: 72, cost: 38 },
  { month: "Jun", revenue: 68, cost: 41 },
]
</script>

<template>
  <q-chart
    title="Revenue, labeled"
    :height="260"
    :marks="[
      { type: 'bar', data: monthly, x: 'month', y: 'revenue', fill: 'chart-1', name: 'Revenue' },
      {
        type: 'text',
        data: monthly,
        x: 'month',
        y: 'revenue',
        text: (d) => `${d.revenue}`,
        lineAnchor: 'bottom',
        dy: -6,
        fill: 'primary',
        fontWeight: 'bold',
      },
      { type: 'rule', y: [50], stroke: 'chart-5' },
    ]"
  />
</template>
```

::

The mark itself is invisible: the label is drawn on a **1 px transparent anchor** placed at
`x` / `y`, so nothing else appears on the chart. `lineAnchor: 'bottom'` lifts the text above
the point and `dy: -6` adds a few pixels of air above the bar.

### Position

`x` and `y` are the same channels as everywhere else. By default the text is **centred on
the point** — `textAnchor: 'middle'` and `lineAnchor: 'middle'`, the Plot default. Both
anchors are *constants* (they apply to the whole mark), while `dx` / `dy` shift the label in
pixels and can vary per row:

| Anchor | Where the point sits on the text | Typical use |
| --- | --- | --- |
| `textAnchor: 'start'` | Left edge (text extends to the right) | Left-aligned annotation |
| `textAnchor: 'middle'` (default) | Centre | Label centred on a bar |
| `textAnchor: 'end'` | Right edge (text extends to the left) | Right-aligned annotation |
| `lineAnchor: 'top'` | Top edge (text hangs **below** the point) | Label inside a bar |
| `lineAnchor: 'middle'` (default) | Centre | Centred label |
| `lineAnchor: 'bottom'` | Bottom edge (text sits **above** the point) | Value on top of a bar |

```ts
{ type: 'text', data: rows, x: 'month', y: 'revenue', text: 'revenue' }                       // centred
{ type: 'text', data: rows, x: 'month', y: 'revenue', text: 'revenue', lineAnchor: 'bottom', dy: -6 }
{ type: 'text', data: rows, x: 'month', y: 'revenue', text: 'month', textAnchor: 'end', dx: -8 }
```

With **neither `x` nor `y`**, the data is a list of pairs `[[x₀, y₀], [x₁, y₁], …]` (Plot's
shorthand), and the default label is the row index:

```ts
{ type: 'text', data: [[0, 4], [1, 7], [2, 5]], text: (d) => `${d[1]} %` }
```

### Content

| `text` | Result |
| --- | --- |
| a field name | That field of each row |
| explicit values / an accessor | One label per row (`(d, i) => …`) |
| omitted | The row itself for primitive data (`[42, 51]`), its **index** for objects — as in Plot |
| a string with `\n` | Several lines (the line breaks are rendered) |
| a per-row channel | `fill`, `fontSize`, `rotate`… see below |

### Font

| Key | Effect |
| --- | --- |
| `fontSize` | Size in pixels — **11 by default**, constant or channel |
| `fontWeight` | `bold`, `600`… |
| `fontFamily` | Font name (the host font by default) |
| `fontStyle` | `italic`, `oblique` |
| `lineHeight` | Line height in pixels, once the text has several lines |
| `rotate` | Degrees, **clockwise** — the sign is flipped for you when the underlying label turns the other way. Constant or channel. |

### Wrapping and truncating

`lineWidth` is a width in **ems** (as in Plot): beyond it the text wraps. Text is measured
approximately, exactly like Plot's own heuristic, so hard-wrap with `\n` when the result
matters. `textOverflow` truncates lines that are too long:

| `textOverflow` | Result |
| --- | --- |
| *(omitted)* | Overflowing characters are kept |
| `ellipsis` / `ellipsis-end` | End replaced with an ellipsis (…) |
| `clip` / `clip-end` | Cut at the end, no ellipsis |

Plot's `-start` / `-middle` variants are not available and fall back to the end.

### Colour and halo

| Key | Effect |
| --- | --- |
| `fill` | Colours the **text**. |
| `stroke` alone | Also colours the text (like a `dot`), with no halo. |
| `fill` + `stroke` + `strokeWidth` | Draws a **halo** around the text — the usual trick to keep labels readable over bars or a busy background. `strokeWidth` is 3 px by default, as in Plot. |
| `opacity` | Applies to the label. |

```ts
{ type: 'text', data: rows, x: 'month', y: 'revenue', text: 'revenue', fill: 'primary' }
{ type: 'text', data: rows, x: 'month', y: 'revenue', text: 'revenue', fill: '#fff', stroke: '#1d1d1d' }  // halo
```

### Tooltips

With `title`, hovering a label shows that value — give it a field name, explicit values or
an accessor. A chart made **only** of labels (or dots) is hovered
label by label; as soon as a `line` or a `bar` shares the chart, the tooltip switches to the
whole axis, as on the [Line](</docs/charts/line>) page.

### Not covered

The label is placed by the **data**; Plot's `frameAnchor` (text pinned to a corner of the
plot frame, with no `x` / `y`) has no equivalent — use the `options` prop and a `graphic`
element for that. `monospace`, the soft-hyphen line breaking and `paintOrder: 'fill'` are
not exposed either.

Marks, channels and the axis/format props are listed on the
[Line](</docs/charts/line>) page — every page uses the same `q-chart`.
